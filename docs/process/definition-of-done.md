# Definition of Done

A change is done only when it works, is documented, and does not leave open technical uncertainty.

## Checklist

- Acceptance criteria are met
- Code compiles: `tsc --noEmit` passes
- Tests pass where applicable
- Relevant docs are updated
- No unresolved open questions remain
- For API changes: the endpoint is documented
- For agent-facing changes: audit logging is verified
- For schema changes: a migration is created
