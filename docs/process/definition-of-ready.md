# Definition of Ready

A task, feature, or epic is ready only when the problem is understood and the implementation boundary is clear.

## Checklist

- Problem / goal is clear
- Scope is explicit, with non-goals listed
- Acceptance criteria are testable
- Dependencies are identified
- Data / API impact is documented
- Related docs are linked: epic, feature, architecture
- Open questions are answered or explicitly deferred

## Missing information policy

If anything essential is unclear, do not guess. Record the open question and stop.
